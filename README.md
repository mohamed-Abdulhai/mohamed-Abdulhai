## Projects

### Bike Sales Data Pipeline

A data engineering project built with **Databricks and PySpark** that processes bike sales data using a **Medallion Architecture** approach.

Key ideas implemented in this project:

- Data ingestion and transformation using **PySpark**
- Layered data architecture (**Bronze → Silver → Gold**)
- Data cleaning and transformation pipelines
- SQL-based analytics queries
- Storage using **Delta Lake**
